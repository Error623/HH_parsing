## HH Bot

# Телеграм-бот на Python с использованием асинхронной библиотеки для разработки тг-ботов aiogram. Парсит вакансии с сайта HH.ru через их официальный API.

## Возможности
- Поиск по вакансиям(пользователь вводит например и отправляет в чат Python, Java, C++ и т.д. В ответ он получает вакансии 5 штук)
- Вывод вакансии (название самой вакансии, компании и ссылка)
- Сохранение запроса пользователя
- Подписка на рассылку вакансий
- Отписка от рассылки
- Автоматическая рассылка вакансий(задействованны Celery + Redis)
- Хранение пользователей в БД PostgreSQL

## Cтек
Python 3.10+
aiogram 3
PostgreSQL
Redis
Celery
httpx(необходим, чтобы делать запросы к API HH.ru, иначе без него работать не будет)
dotenv

## Структура проекта
```
│
├── handlers/ # обработчики Telegram
├── keyboards/ # клавиатуры
├── services/ # работа с API 
├── database/ # Работа с БД 
├── celery_app.py # конфиг celery
├── tasks.py # фоновые задачи (рассылка)
├── main.py # запуск бота
└── .env # переменные окружения
```

## Запуск проекта
1. Клонируйте этот репозитой - git clone https://github.com/Error623/HH_parsing.git
2. Создайте у себя виртуальное окружение - python -m venv venv
3. Установите зависимости - pip install -r requirements.txt
4. Создайте у себя .env по примеру env_example.env и в переменные вставьте токен вашего бота и пути к БД, Redis и прочее.
5. После установки зависимостей, выполните следующую команду, которую запустит этот проект - python main.py
